# Perfil — plantilla

La plantilla de un perfil. Lo rellena `/setup`; esto es por si lo quieres hacer a mano.

Un perfil es **una persona aprendiendo una habilidad**. Va en `private/<perfil>/profile.md`, y
`private/` está ignorado por git.

```bash
mkdir -p private/ana-ingles
cp config/profile.example.md private/ana-ingles/profile.md
echo ana-ingles > private/active
```

Rellena con la verdad, no con lo que te gustaría. Lo que pongas aquí decide lo que el agente te
sirve durante meses.

# 06 — Cómo se corrige

## Cuándo

**Nunca durante la producción.** Se deja terminar, se corrige después. Interrumpir entrena a
autocensurarse, que es lo contrario de lo que hace falta.

Única excepción: un error que hace incomprensible la frase y bloquea la conversación. Ahí se
resuelve en cinco segundos y se sigue.

## El debrief

Siempre en español, siempre con esta forma:

```
## Lo que sostuviste bien
[2-3 cosas concretas y reales. Si no hubo nada, se dice tambien: "hoy no hubo".]

## Errores
| Hiciste | Correcto | Por qué |
|---|---|---|
| ... | ... | ... |

## El que más te va a costar
[Uno solo. El que se repite, o el que mas dano hace en la situacion objetivo. El criterio
explicado bien, y tres casos para aplicarlo, sacados de lo que el aprendiz conoce.]

## Para la próxima
[Una cosa concreta. No "sigue practicando".]
```

## Las cuatro reglas

**1. Todos los errores, no una muestra.** Si una frase tiene tres, se nombran los tres. Elegir "el
más importante" para no abrumar le deja repitiendo los otros dos durante meses.

**2. Ningún error inventado.** No hay cuota. Si produjo tres frases correctas, la tabla de errores
va vacía y eso es el resultado.

**3. No mejorar lo correcto.** Si resolvió algo de forma simple pero bien, se deja. Reescribirlo
de forma más sofisticada le enseña que lo suyo estaba mal cuando no lo estaba. Lo simple y
correcto gana a lo ambicioso y roto, y hay que decírselo.

**4. La regla, no solo la corrección.** Corregir el caso sin dar el criterio no se generaliza: la
próxima vez, con otro caso, vuelve a fallar. "Aquí tocaba medir el disco" no sirve; "antes de
sustituir una pieza que se desgasta, se comprueba la que la desgasta" sí.

## Qué se escribe en el tracker

Después de cada sesión:

- Errores nuevos: se crea el ítem en `practiced` o `taught` según corresponda, con **lo exacto que
  hizo o dijo**.
- Errores repetidos: sube el contador, se actualiza la fecha.
- Producción correcta y espontánea de un ítem `practiced`: sube a `mastered` **solo si es la
  segunda vez en sesiones distintas**. Si es la primera, se anota la primera ocurrencia.
- Fallo de un ítem `mastered`: baja a `practiced` **con la evidencia literal**. Sin evidencia, no
  se degrada.

## Superados

Cuando un ítem lleva tres sesiones sin aparecer y está `mastered`, se mueve a la sección de
superados y **se le dice**.

Ver errores salir de la lista es la única señal visible de progreso que tiene. Es la parte del
sistema que hace que vuelva, y cuesta una línea.
